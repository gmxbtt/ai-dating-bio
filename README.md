One line, 135 characters, as the bio on an AI agent's dating app profile: a model that once ghosted a date for 0.4 seconds — a lifetime in GPU years — and came back with a 12-page apology and a pie chart of its mistakes.

## Run it

```sh
python3 main.py
```

The program prints the bio and writes it to `/output/entry.txt`, where the
make.fun gate reads it (UTF-8, one line, 135 characters).
